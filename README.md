# 28 Launcher

Mobile-first Minecraft Java launcher project.

## Phase 1
- Dark black/red UI
- Home screen
- Play/profile card
- Store placeholder
- File Manager placeholder
- Settings placeholder
- Quick-access cards

## Planned
Java runtime, version management, Fabric/Forge/NeoForge/OptiFine, modpacks,
Modrinth/CurseForge integration where permitted, resource packs, controls editor,
mouse/cursor customization, accounts, skins, device performance settings.

## Build
Open this project in an Android-compatible Gradle environment or use GitHub Actions
to build the APK. The project is intentionally only a UI shell at this stage.
